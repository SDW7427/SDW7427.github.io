# バブリンコ (BabblingKO) ランディングページ

外国人韓国語学習者向けの発音矯正およびハングル学習ゲーム「バブリンコ」のランディングページです。

## 📋 プロジェクト概要

韓国語発音が難しい外国人韓国語学習者のための韓国語学習・発音矯正ソリューション「バブリンコ」のランディングページです。

## ✨ 実装済み機能

### 1. 完全レスポンシブデザイン
- **PC（1920px以上）**: フルスクリーン 1920x1080 レイアウト
- **ノートブック（1281px～1920px）**: 16:9 アスペクト比維持、動的スケーリング
- **タブレット（769px～1280px）**: 縦型レイアウト、中央揃え
- **モバイル（768px以下）**: モバイル最適化レイアウト

### 2. 多言語対応（i18n）
- **対応言語**: 日本語（ja）、韓国語（ko）、英語（en）
- **リアルタイム言語切り替え**: ヘッダーの言語セレクターで即座に切り替え
- **自動ローカライズ**: ロゴ、アプリバッジ、すべてのテキストが言語に応じて変更
- **ローカルストレージ保存**: 選択した言語を記憶

### 3. スクロールアニメーション
- **Intersection Observer API**使用
- スクロール時のフェードインエフェクト（`.fade-in-up`）
- 段階的表示（stagger animation）
- 高パフォーマンス・軽量実装

### 4. セクション構成

#### セクション3: 機能2 - タイミング練習
- タイミングと手書き練習機能
- 右左レイアウト（テキスト＋画像）

#### セクション4: 機能3 - コミュニティ
- ユーザーコミュニティとサポート
- 左右レイアウト（画像＋テキスト）

## 🌐 多言語システム (i18n)

### 言語切り替え方法
1. ヘッダー右上の言語セレクターをクリック
2. 日本語 / 한국어 / English から選択
3. ページ全体が即座に切り替わり、ローカルストレージに保存

### 対応コンテンツ
- ページタイトル・メタタグ
- ヘッダーロゴ
- すべてのセクションテキスト
- App Store / Google Play バッジ
- フッター情報
- ファビコン

### 技術実装
- **i18n-v3.js**: 翻訳データとロジック
- **data-i18n属性**: HTML要素に自動適用
- **localStorage**: 言語設定の永続化

## 📝 カスタマイズ方法

### カラーの変更
`css/style.css`の`:root`セクションを編集：
```css
:root {
    --primary-color: #FF9B5A;  /* ここを変更 */
    --secondary-color: #FFD700;
    /* ... */
}
```

### テキストの変更
`js/i18n-v3.js`の翻訳データを編集：
```javascript
const translations = {
    ja: {
        'hero-title': '新しいテキスト',
        // ...
    }
}
```

### 新しい言語の追加
1. `i18n-v3.js`に新しい言語オブジェクトを追加
2. `index.html`の言語セレクターに選択肢を追加
3. 対応する画像（ロゴ、バッジ）を用意
