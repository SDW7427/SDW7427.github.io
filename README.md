# バブリンコ ランディングページ

就労継続を支えるハングル学習ゲーム「パブリンコ」のランディングページです。

## 📋 プロジェクト概要

外国人保護者が日本語を学習し、子どもの学校プリントを理解できるよう支援するスマホアプリケーションのランディングページです。

## ✨ 実装済み機能

### 1. レスポンシブデザイン
- モバイル、タブレット、デスクトップに完全対応
- ブレークポイント：768px、480px

## 🎭 アニメーション効果の使い方

### 既存の要素にアニメーションを追加
HTMLの要素に以下のクラスを追加するだけで、スクロールアニメーションが適用されます：

```html
<!-- 基本的なフェードイン -->
<div class="fade-in">コンテンツ</div>

<!-- 下からフェードイン -->
<div class="fade-in-up">コンテンツ</div>
```

### 新しい画像要素の追加
個別の画像を追加する場合は、以下の構造を使用してください：

```html
<section class="feature">
    <div class="container">
        <div class="feature-content">
            <div class="feature-image fade-in-up">
                <img src="images/your-image.png" alt="説明">
            </div>
            <div class="feature-text fade-in-up">
                <h3 class="feature-title">タイトル</h3>
                <p class="feature-description">説明文</p>
            </div>
        </div>
    </div>
</section>
```

## 📝 メンテナンス

### 画像の更新方法
1. `images/`フォルダに新しい画像を配置
2. HTMLファイル内のsrc属性を更新
3. alt属性も適切に更新

### テキストの更新方法
1. `index.html`を開く
2. 該当セクションのテキストを編集
3. ブラウザで確認

### スタイルのカスタマイズ
1. `css/style.css`を開く
2. `:root`セクションのCSS変数を編集してカラーを変更
3. 各セクションのスタイルを直接編集
